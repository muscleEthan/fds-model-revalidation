# IEEE-CIS 이상거래탐지(FDS) 모델 평가 재검증

SeSAC 'AI로 완성하는 핀테크 데이터 분석가 양성과정' 4인 팀 프로젝트(우수상, 2026.09) 종료 후,
심사 피드백 중 모델·평가 관련 질문 8개를 노트북에서 재계산·비교 실험으로 확인한 개인 보완 작업입니다.

## 팀 작업과 개인 작업

- 피처 엔지니어링, 모델링(XGBoost), 임계치·비용 산출은 조원들의 작업입니다.
- 이 노트북은 팀 작업을 재현한 뒤 개인 보완을 덧붙였고, 셀마다 팀 작업과 개인 보완을 구분해 표시했습니다.
- 채택·기각 기준은 실험 전에 정했고(PR-AUC +0.003 이상, 3개월 중 2개월 상승), 성능이 오르지 않은 실험도 기각 사유와 함께 기록했습니다.

## 주요 결과

| 심사 질문 | 확인 결과 |
|---|---|
| 학습 데이터에 미래 정보가 섞였을 가능성 | 집계 피처를 각 fold의 학습 기간 거래만으로 다시 계산하고 early stopping 기준을 바꾸자, 같은 모델의 PR-AUC가 0.708 → 0.657 (모델이 아니라 평가 조건의 차이) |
| 성능 개선 | 사전 기준을 통과한 XGBoost+LightGBM 앙상블만 채택: PR-AUC 0.662 |
| 의심 기준값 통일 (0.0329 / 0.35 / 0.017) | 후보 7개를 같은 예측 점수·같은 비용식으로 비교해 0.036 권장 (같은 OOF에서 선택했으므로 독립 평가는 아니며, 월별 재계산으로 안정성 점검) |
| 비용 가정 민감도 | 27개 조합 모두에서 모델 사용 쪽의 계산상 총비용이 11~86% 낮음 (가정 기반 비교) |
| 국내 적용 시 차이 | 이메일·지역 변수 제외 시 PR-AUC −0.069 → 대응 변수 재설계 필요 |
| 룰 선처리 | 룰 적용 전후 Recall 80% 알림 차이 10건 → 룰 패턴이 모델 점수에 이미 반영된 것으로 판단 |
| 지연시간 | 거래 1건 모델 추론 중간값 1.06ms (피처 생성·데이터 조회 시간 제외) |

- 원본 데이터는 Kaggle [IEEE-CIS Fraud Detection](https://www.kaggle.com/c/ieee-fraud-detection)에서 내려받아야 하며, 재배포 규정상 저장소에 포함하지 않았습니다.
- 팀 코드와 팀 산출물(OOF 예측, Time Consistency 결과)도 포함하지 않았습니다. 결과는 노트북에 저장된 실행 출력과 `results/`에서 확인할 수 있습니다.
